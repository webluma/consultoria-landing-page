# Vanturel Consultoria - Landing Page Premium

Landing page moderna, elegante e responsiva desenvolvida pela Webluma para apresentacao de uma consultoria financeira e empresarial com posicionamento premium.

O projeto foi criado com foco em design estrategico, experiencia do usuario, percepcao de valor e conversao, simulando uma pagina real para um negocio de consultoria voltado para empresas que buscam clareza, controle e crescimento com mais maturidade.

## Sobre o projeto

A Vanturel Consultoria e uma landing page conceitual desenvolvida para demonstrar como uma consultoria de servicos pode se posicionar de forma mais profissional, sofisticada e comercialmente atrativa no ambiente digital.

A pagina apresenta uma estrutura completa de conversao, com:

- Hero section com proposta de valor clara
- Secao de indicadores e credibilidade
- Apresentacao da proposta de consultoria
- Escopo de servicos
- Metodo de trabalho
- Bloco de resultados esperados
- Apresentacao institucional da marca
- Chamada final para diagnostico
- Footer institucional

O objetivo principal do projeto e mostrar como uma landing page bem estruturada pode transmitir confianca, valor percebido e profissionalismo para clientes reais.
